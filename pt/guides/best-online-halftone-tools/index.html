★★★★★

1. ScreenPrintFilter.online

https://screenprintfilter.online

A ferramenta que você está usando atualmente. Faz uma coisa — conversão halftone — e tenta fazer bem. Tudo funciona no navegador usando Canvas. Sem uploads de arquivo, sem servidores, sem contas.

✓ Prós
  • Realmente gratuito, sem limites ocultos
  • Visualização em tempo real ao ajustar sliders
  • Saída em resolução completa
  • 4 formas de ponto
  • Suporte a desfazer/refazer
  • Zoom + lupa para ver detalhes
  • Sem uploads = privado
✗ Contras
  • Apenas 4 formas de ponto (sem padrões personalizados)
  • Sem separação de cor multicanal
  • Ferramenta de página única, não um editor completo
Melhor para: serígrafos que querem uma conversão halftone rápida, gratuita, direta com controle total.
★★★☆☆

2. IMG online (imgonline.com)

https://www.imgonline.com.ua

Um site antigo que parece que foi desenhado em 2008. Funciona, mas mal. Você carrega sua imagem, define alguns parâmetros, clica em um botão, espera o servidor processar, e baixa o resultado. Sem visualização. Sem iteração. Se as configurações estão erradas, você começa de novo.

✓ Prós
  • Gratuito
  • Tem algumas outras ferramentas de imagem também
  • Funciona em apertos
✗ Contras
  • Sem visualização — chute e verifique
  • Envia seus arquivos para o servidor deles
  • Resolução de saída limitada
  • UI parece antiga
  • Apenas pontos círculo
Use se nada mais funcionar e você está em um computador realmente antigo.
★★★★☆

3. Halftone Pro (halftonepro.com)

https://halftonepro.com

Uma ferramenta mais polida que funciona como PWA. Tem mais formas de ponto que a maioria das ferramentas gratuitas e lida bem com imagens maiores. O problema é o modelo de preços — $15/mês para uma ferramenta que só faz halftones. Para profissionais fazendo isso diariamente, pode valer a pena. Para uso ocasional, a assinatura parece cara.

✓ Prós
  • 6 formas de ponto incluindo cruz e estrela
  • Boa visualização em tempo real
  • Funciona offline (PWA)
  • Processamento client-side
✗ Contras
  • $15/mês é caro para uma ferramenta única
  • Sem nível gratuito com recursos completos
  • Pode parecer superengenhado para tarefas simples
Bom se você faz trabalho halftone todos os dias e quer as formas extras. Exagerado para todos os outros.
★★★☆☆

4. Photopea (photopea.com)

https://www.photopea.com

Photopea é um clone gratuito do Photoshop online. É incrivelmente poderoso para um aplicativo web. Você pode fazer efeitos halftone através do menu de filtros, mas não é direto. Você precisa converter para escala de cinza, aplicar o filtro Halftone de Cor, ajustar as configurações de canal manualmente... leva alguns minutos mesmo se você conhece os passos. Se você já usa Photopea para outros trabalhos de imagem, faz sentido. Se tudo que você precisa é um halftone, é desnecessariamente complicado.

✓ Prós
  • Editor de fotos completo gratuito
  • Muito controle se você sabe o que está fazendo
  • Sem uploads necessários
✗ Contras
  • Curva de aprendizado íngreme para halftones
  • Sem visualização halftone dedicada
  • Interface em camadas é exagero
  • Anúncios na versão gratuita
Apenas use Photopea para halftones se você já conhece o software. Caso contrário, você está melhor com uma ferramenta dedicada.
★★☆☆☆

5. ConvertImage (convertimage.net)

https://convertimage.net

Um desses sites que faz cem conversões de imagem diferentes e nenhuma particularmente bem. O recurso halftone existe, mas está enterrado. Você carrega sua imagem, escolhe o efeito, e o site coloca uma marca d'água na saída a menos que você pague. A resolução de saída também é limitada a um nível bastante baixo. Honestamente, pule este.

✓ Prós
  • Tem outras ferramentas de imagem incluídas
  • Gratuito com marca d'água
✗ Contras
  • Marca d'água na versão gratuita
  • Processamento no servidor (uploads)
  • Saída de baixa resolução
  • Apenas 2 tipos de padrão
  • Lento
Não recomendado. Existem muitas opções gratuitas melhores.
