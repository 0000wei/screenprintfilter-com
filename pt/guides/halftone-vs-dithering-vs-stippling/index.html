Halftone vs Dithering vs Stippling vs Mezzotint: Qual é a Diferença?

Publicado: 21 de maio de 2026 • 6 min de leitura

Se você tem procurado maneiras de transformar imagens em padrões de pontos, você provavelmente viu esses quatro termos sendo usados. Eles soam parecidos, todos envolvem pontos, mas funcionam de maneiras muito diferentes. E se você escolher o errado para seu projeto, o resultado ficará estranho.

Aqui está uma análise direta de cada técnica, quando usá-las, e as diferenças práticas que importam.

Mais Prático

Halftone

Halftone é o padrão para serigrafia e impressão comercial. Funciona colocando uma grade uniforme e variando o tamanho de cada ponto. Partes escuras da imagem recebem pontos grandes, partes claras recebem pequenos. Porque os pontos estão em uma grade, eles imprimem de forma previsível e consistente.

A grade pode ser rotacionada (chamada de ângulo de tela) para evitar padrões de moiré ao imprimir múltiplas cores. Na serigrafia, diferentes ângulos são usados para cada cor de tinta para que os pontos não colidam. Isso está entrando em território avançado, mas é bom saber que o sistema foi construído para isso.

Vantagem chave: Funciona. Serígrafos têm usado halftones por décadas. A técnica é comprovada, as ferramentas são maduras, e os resultados são repetíveis.

Melhor para Pixel Art

Dithering

Dithering usa pontos de tamanho fixo colocados em posições variadas para criar a ilusão de tons. Pense em jogos de vídeo antigos — os padrões de xadrez em jogos de Super Nintendo, o visual granulado dos primeiros gráficos de computador. Isso é dithering.

Os pontos são do mesmo tamanho em todos os lugares. Para fazer uma área mais escura, você amontoa mais pontos mais próximos. Para fazer mais clara, você os espalha. Existem vários algoritmos para isso — Floyd-Steinberg, Bayer, Atkinson — cada um produzindo um padrão diferente.

Dithering está fazendo um comeback na pixel art e design retro. Mas para serigrafia real, raramente é a escolha certa. A colocação de pontos inconsistente torna mais difícil queimar telas limpas, e os resultados são menos previsíveis em tecido.

Vantagem chave: Ótimo para arte digital e ambientes de baixa cor. Não ideal para impressão de produção.

Mais Artístico

Stippling

Stippling é uma técnica desenhada à mão onde um artista cria uma imagem colocando milhares de pontos individuais. Cada ponto é do mesmo tamanho — a escuridão vem de quão densamente os pontos são colocados. É incrivelmente demorado, mas produz resultados lindos e orgânicos.

Existem ferramentas digitais que tentam automatizar stippling, mas raramente parecem tão bons quanto a coisa real. O problema é que stippling feito por humanos tem irregularidade intencional — o artista instintivamente varia a densidade baseado no que parece certo, não no que um algoritmo calcula.

Para serigrafia, stippling é impraticável a menos que você esteja fazendo uma corrida pequena de impressões altamente artísticas. O espaçamento irregular pode causar problemas com queima de tela e fluxo de tinta.

Vantagem chave: Visual artesanal deslumbrante. Impraticável para trabalho de produção.

Apenas Arte Fina

Mezzotint

Mezzotint é uma técnica de gravação do século 17. Em vez de pontos, o artista áspera a superfície de uma placa de metal com uma ferramenta chamada rocker, criando uma superfície texturizada que segura tinta. Áreas mais suaves imprimem mais claras, áreas mais ásperas imprimem mais escuras.

Filtros modernos de mezzotint digital tentam simular isso adicionando ruído aleatório e textura a uma imagem. Raramente parecem convincentes. Mezzotint real tem profundidade e riqueza que filtros digitais não conseguem replicar totalmente.

A menos que você esteja fazendo impressões de arte fina, você provavelmente não precisa de mezzotint. É mais uma técnica histórica que ocasionalmente é referenciada no design moderno.

Vantagem chave: Tons profundos e ricos. Caso de uso nicho na era digital.

Qual Deve Usar?

Aqui está a versão curta:

  • Se você está fazendo serigrafia de camisetas ou pôsteres, use halftone. É a ferramenta feita para o trabalho.
  • Se você está fazendo pixel art ou gráficos de jogos retro, use dithering. Encaixa na estética.
  • Se você está criando ilustrações desenhadas à mão, tente stippling. Mas limpe sua agenda.
  • Se você está fazendo impressões de arte fina, mezzotint é uma opção. Mas você provavelmente já sabe disso.

Linha de fundo: Para 90% do que as pessoas precisam — transformar uma foto em um padrão de pontos imprimível — halftone é a resposta. Posso Combiná-los?

Às vezes. Designers ocasionalmente misturam halftone com dithering para efeitos experimentais. Alguns designs de camiseta usam uma base halftone com elementos desenhados à mão stippling sobrepostos. Mas geralmente, escolha uma técnica e faça bem. Combiná-los geralmente parece bagunçado a menos que você tenha uma razão artística clara.
