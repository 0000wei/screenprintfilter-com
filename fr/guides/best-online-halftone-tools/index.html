★★★★★

1. ScreenPrintFilter.online

https://screenprintfilter.online

L'outil sur lequel vous êtes actuellement. Il fait une chose — la conversion halftone — et essaie de bien la faire. Tout s'exécute dans le navigateur en utilisant Canvas. Pas de téléchargement de fichiers, pas de serveurs, pas de comptes.

✓ Avantages
  • Vraiment gratuit, pas de limites cachées
  • Aperçu en temps réel pendant l'ajustement des curseurs
  • Sortie à pleine résolution
  • 4 formes de points
  • Support annuler/rétablir
  • Zoom + loupe pour vérification des détails
  • Pas de téléchargement = privé
✗ Inconvénients
  • Seulement 4 formes de points (pas de motifs personnalisés)
  • Pas de séparation de couleurs multi-canaux
  • Outil à page unique, pas un éditeur complet
Mieux pour : les sérigraphes qui veulent une conversion halftone rapide, gratuite, sans废话, avec un contrôle complet.
★★★☆☆

2. IMG online (imgonline.com)

https://www.imgonline.com.ua

Un site web à l'ancienne qui a l'air d'avoir été conçu en 2008. Il fonctionne, mais à peine. Vous téléchargez votre image, définissez quelques paramètres, appuyez sur un bouton, attendez que le serveur la traite, et téléchargez le résultat. Pas d'aperçu. Pas d'itération. Si les paramètres sont faux, vous recommencez.

✓ Avantages
  • Gratuit
  • A aussi d'autres outils d'image
  • Fonctionne en cas de besoin
✗ Inconvénients
  • Pas d'aperçu — devinez et vérifiez
  • Télécharge vos fichiers sur leur serveur
  • Résolution de sortie limitée
  • Interface paraît ancienne
  • Seulement des points cercle
À utiliser si rien d'autre ne fonctionne et que vous êtes sur un vraiment vieil ordinateur.
★★★★☆

3. Halftone Pro (halftonepro.com)

https://halftonepro.com

Un outil plus poli qui fonctionne comme PWA. Il a plus de formes de points que la plupart des outils gratuits et gère bien les grandes images. Le piège est le modèle de prix — 15 $/mois pour un outil qui ne fait que des halftones. Pour les professionnels qui font cela quotidiennement, cela peut en valoir la peine. Pour une utilisation occasionnelle, l'abonnement paraît cher.

✓ Avantages
  • 6 formes de points incluant croix et étoile
  • Bon aperçu en temps réel
  • Fonctionne hors ligne (PWA)
  • Traitement côté client
✗ Inconvénients
  • 15 $/mois est cher pour un seul outil
  • Pas de niveau gratuit avec toutes les fonctionnalités
  • Peut paraître surconçu pour les tâches simples
Bien si vous faites du travail halftone tous les jours et voulez les formes supplémentaires. Trop pour tout le monde.
★★★☆☆

4. Photopea (photopea.com)

https://www.photopea.com

Photopea est un clone Photoshop gratuit en ligne. C'est incroyablement puissant pour une application web. Vous pouvez faire des effets halftone via le menu des filtres, mais ce n'est pas direct. Vous devez convertir en niveaux de gris, appliquer le filtre Halftone Couleur, ajuster manuellement les paramètres des canaux... cela prend quelques minutes même si vous connaissez les étapes. Si vous utilisez déjà Photopea pour d'autres travaux d'image, cela a du sens. Si tout ce dont vous avez besoin est un halftone, c'est inutilement compliqué.

✓ Avantages
  • Éditeur photo complet gratuit
  • Beaucoup de contrôle si vous savez ce que vous faites
  • Pas de téléchargement nécessaire
✗ Inconvénients
  • Courbe d'apprentissage difficile pour les halftones
  • Pas d'aperçu halftone dédié
  • Interface en couches est exagérée
  • Publicités sur la version gratuite
N'utilisez Photopea pour les halftones que si vous connaissez déjà le logiciel. Sinon, vous êtes mieux avec un outil dédié.
★★☆☆☆

5. ConvertImage (convertimage.net)

https://convertimage.net

Un de ces sites qui fait une centaine de conversions d'image différentes et aucune particulièrement bien. La fonctionnalité halftone existe mais elle est enterrée. Vous téléchargez votre image, choisissez l'effet, et le site met un filigrane sur la sortie à moins que vous ne payiez. La résolution de sortie est également limitée assez bas. Honnêtement, sautez celui-ci.

✓ Avantages
  • A d'autres outils d'image regroupés
  • Gratuit avec filigrane
✗ Inconvénients
  • Filigrane sur la version gratuite
  • Traitement côté serveur (téléchargements)
  • Sortie faible résolution
  • Seulement 2 types de motifs
  • Lent
Pas recommandé. Il y a trop d'options gratuites meilleures.
