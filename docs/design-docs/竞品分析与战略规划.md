## **1\. 产品愿景与设计哲学**

### **1.1 核心愿景**

打破 Magnific AI 等高价通用软件建立的商业壁垒，为全球印前设计师与服装印花从业者提供专业、确定且完全免费的图像预处理工具链。

## **2\. 核心功能模块详细需求**

### **2.1 模块一：自适应双模 AI 增强引擎 (Adaptive AI Engine)**

针对 Magnific 容易在商业图纸上产生“过度幻觉”的缺陷，提供两种核心增强模式：

| 功能子项 | 需求描述 | 验收标准 |
| :---- | :---- | :---- |
| **忠实精准模式 (Precision Mode)** | 基于高保真超分辨率算法，仅提升画质与高频边缘，严禁凭空添加任何新语义特征。适用于 Logo、文字及几何图案。 | 结构相似性指数 SSIM≥0.95；矢量文字边缘无锯齿、无形变。 |
| **可控重构模式 (Controlled Mode)** | 允许微调纹理丰富度（Creativity 0-10），但强制引入**语义安全区锁（Safety Masking）**。 | 系统自动识别图像中的人脸与文字区域并强制应用低 Creativity，防止人脸走样与字体扭曲。 |

### **2.2 模块二：印前自动化流水线 (Prepress Pipeline)**

将 AI 放大过程与传统印前软件（Prepress）的繁琐工序合并：

#### **1\. 物理尺寸与 DPI 智能重采样**

用户输入目标印刷物理尺寸（如 12×18 inches），系统依据下式自动计算目标像素尺寸 *W*px​×*H*px​，并在导出的文件头中真实写入 300 DPI 元数据（Header Metadata），防止印刷设备提示分辨率不够：

*W*px​\=*W*inch​×300  
*H*px​\=*H*inch​×300

#### **2\. Alpha 透明通道保护与背景一键抠除 (Knockout)**

> * 自动识别图像背景（白色/黑色/单色底），一键生成带平滑透明边缘（Smooth Alpha）的 PNG/TIFF。  
> * AI 生成算法仅在非透明色彩区域生效，严禁向透明背景区填充杂色与伪影。

#### **3\. 半色调挂网引擎 (Halftone Dot Engine)**

> * 内置针对服装印花优化的 35 LPI \- 55 LPI AM（调幅）圆形网点算法。  
> * 放大后的图像可直接预览挂网效果并导出为网点菲林图（Film Positive），适配 DTF 及丝网印刷。

### **2.3 模块三：局部 ROI 即时预览与交互 (UX & Regional Preview)**

为了避免传统工具“渲染整图耗时数分钟才发现效果不对”的问题：

> * **局部 ROI 框选**：用户可在画布上拖拽选框（如 256×256 px），仅对关键区域进行 AI 渲染。  
> * **3 秒极速响应**：局部预览渲染时间控制在 3 秒 以内。  
> * **左右滑动分屏对比 (Split View)**：提供类似对比滑块，让用户直观比对原图与放大后的网点/细节。

### **2.4 模块四：工作流生态扩展 (Plugins)**

> * **Photoshop / Figma 原生插件**：用户无需离开设计画布，框选图层后点击“一键 300 DPI 增强”，直接在当前画布生成高精矢量/点阵图层。

### **2.5 模块五：免费印前工具矩阵 (PLG 流量入口)**

无需注册账户，纯前端 JavaScript 运行（数据不上传服务器，保护隐私且降低你的服务器成本）：

> 1. **Gang Sheet 拼版省料计算器**：自动计算 DTF 膜卷的最省排版方案。  
> 2. **印前 DPI 检测与像素换算器**：输入图片尺寸与目标海报大小，一键给出打印质量诊断。  
> 3. **DTF / 丝印挂网实时预览器**：实时呈现不同 LPI 下的半色调效果。

## **3\. 技术架构与成本控制方案（实现“收支平衡”）**

为了确保在 **100% 免费** 的前提下不被高昂的 AI GPU 算力账单压垮，采用以下极简高效的技术架构：

`[前端/浏览器]`   
  `├── 免费工具 (纯 JS/WebGPU 本地运行，0 服务器成本)`  
  `└── ROI 局部预览请求`  
        `│`  
        `▼`  
`[边缘轻量推理网关]`   
  `├── 蒸馏模型 (Distilled Model) 快速处理 2x/4x 基础放大 (低成本)`  
  `└── 复杂潜扩散模型 (仅在极高细节重构时调用)`  
        `│`  
        `▼`  
`[成本回收机制]`  
  `├── 印花设备/墨水厂非侵入式赞助横幅`  
  `└── 谷歌 Google AdSense 广告补足余下开销`

### **3.1 算力降本策略**

> * **蒸馏轻量模型（LCM/Distillation）**：对于 80% 的普通放大请求，采用轻量化超分辨率模型，推理速度提升 5 倍，GPU 显存消耗降低 70%。  
> * **客户端端侧计算（WebGPU）**：挂网、抠图、DPI 重采样等印前工序完全借用用户本地电脑 CPU/GPU 计算，降低服务器开销。

### **3.2 成本回收机制（收支平衡）**

> 1. **行业赞助商模式（Sponsor-Funded）**：在网页页脚及免费小工具页面展示优质印花设备商、DTF 膜材商或墨水厂的赞助 Banner。  
> 2. **非侵入式广告（AdSense）**：在图像生成等待的 3-5 秒间隙或导出成功页，展示轻量广告，收益直接用于抵扣 GPU API 账单。
