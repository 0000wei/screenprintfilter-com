## 翻译规则

1. 品牌名 "ScreenPrintFilter" 保持不翻译
2. 技术术语 (Canvas, SVG, PNG, JPG, WebP, LPI, DPI, HTML5, GA 等) 保持英文
3. <script> 代码块翻译其中的 UI 字符串（alert, 通知文本, 按钮文字），但不能破坏 JS 语法
4. URL、路径、CSS class 名、id 名保持原样
5. <html lang="zh"> 设置 lang
6. 首页是单页应用，需要翻译：
   - <title>、<meta description>
   - OG tags
   - header: logo文字 "ScreenPrintFilter" 不翻译，但导航链接文字翻译
   - hero 区域：标题、副标题、上传按钮文字
   - controls 区域：滑块标签、下拉选项文字
   - features 区域：全部翻译
   - examples 区域：标题翻译，示例名称翻译
   - FAQ 区域：全部翻译
   - footer 文字翻译
   - JS 中的 UI 文字：通知、按钮提示等
7. 子页 (guides)：翻译全部可见文本（title, meta, 文章内容, FAQ）
8. 外部链接不变
9. 子页内链加 /zh/ 前缀
10. 不加 hreflang 标签
