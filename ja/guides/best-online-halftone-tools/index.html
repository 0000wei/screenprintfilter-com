★★★★★

1. ScreenPrintFilter.online

https://screenprintfilter.online

現在いるツール。1つのこと — 網点変換 — をうまくやろうとします。すべて Canvas を使用してブラウザで実行されます。ファイルアップロード、サーバー、アカウントなし。

✓ 長所
  • 実際に無料、隠れた制限なし
  • スライダー調整でリアルタイムプレビュー
  • フル解像度出力
  • 4つのドットシェイプ
  • 元に戻す/やり直し対応
  • 詳細確認のズーム+拡大鏡
  • アップロードなし = プライベート
✗ 短所
  • 4つのドットシェイプのみ（カスタムパターンなし）
  • マルチチャンネル色分離なし
  • 単一ページツール、フルエディタではない
最適: クイックで無料、無駄のない網点変換とフルコントロールを望むスクリーンプリンター向け。
★★★☆☆

2. IMG online (imgonline.com)

https://www.imgonline.com.ua

2008年にデザインされたように見える古風なウェブサイト。機能しますが、かろうじてです。画像をアップロードし、パラメータを設定し、ボタンを押し、サーバー処理を待ち、結果をダウンロードします。プレビューなし。反復なし。設定が間違っている場合、最初からやり直します。

✓ 長所
  • 無料
  • 他の画像ツールもある
  • ピンチで機能する
✗ 短所
  • プレビューなし — 推測で確認
  • ファイルをサーバーにアップロード
  • 出力解像度が制限されている
  • UIが時代遅れ
  • 円形ドットのみ
他が機能しない場合、本当に古いコンピュータを使用している場合に使用してください。
★★★★☆

3. Halftone Pro (halftonepro.com)

https://halftonepro.com

PWAとして実行されるより洗練されたツール。ほとんどの無料ツールよりも多くのドットシェイプを持ち、大きな画像をうまく処理します。課題は価格モデル — 網点のみを行うツールに月$15です。毎日これを行うプロフェッショナルには価値があるかもしれません。時折の使用には、サブスクリプションは高く感じます。

✓ 長所
  • クロスや星を含む6つのドットシェイプ
  • 良好なリアルタイムプレビュー
  • オフラインで動作（PWA）
  • クライアントサイド処理
✗ 短所
  • 単一ツールには$15/月は高い
  • フル機能の無料ティアなし
  • 単純なタスクには過剰エンジニアリング
網点作業を毎日行い、追加のシェイプが欲しい場合に適しています。他には過剰です。
★★★☆☆

4. Photopea (photopea.com)

https://www.photopea.com

Photopeaは無料のオンラインPhotoshopクローンです。ウェブアプリとしては信じられないほど強力です。フィルターメニューを通じて網点エフェクトを行うことができますが、直感的ではありません。グレースケールに変換し、カラーハーフトーンフィルターを適用し、チャンネル設定を手動で調整する必要があります...手順を知っていても数分かかります。他の画像作業で既にPhotopeaを使用している場合、意味があります。網点だけが必要な場合、不必要に複雑です。

✓ 長所
  • 無料のフルフォトエディタ
  • 何をしているか分かれば多くのコントロール
  • アップロード不要
✗ 短所
  • 網点には急な学習曲線
  • 専用の網点プレビューなし
  • レイヤーインターフェイスは過剰
  • 無料版には広告
ソフトウェアを既に知っている場合のみPhotopeaで網点を行ってください。そうでない場合、専用ツールの方が良いです。
★★☆☆☆

5. ConvertImage (convertimage.net)

https://convertimage.net

100種類の異なる画像変換を行い、どれも特にうまくいかないサイトの1つ。網点機能は存在しますが、埋もれています。画像をアップロードし、エフェクトを選択し、支払わない限りサイトが出力に透かしを入れます。出力解像度もかなり低く制限されています。正直、スキップしてください。

✓ 長所
  • 他の画像ツールがバンドルされている
  • 透かし付きで無料
✗ 短所
  • 無料版に透かし
  • サーバーサイド処理（アップロード）
  • 低解像度出力
  • 2つのパターンタイプのみ
  • 遅い
推奨されません。より良い無料オプションが多すぎます。

どれを選ぶべき？

必要なものに依存します：

  • クイックな網点、面倒なし？ ScreenPrintFilter.onlineを使用してください。無料、高速、ローカル実行。
  • より多くのドットシェイプ？ Halftone Proを試してくださいが、支払う準備をしてください。
  • 既にPhotopeaを使用？ それを使い続けてくださいが、フィルターワークフローを学んでください。
  • ただ閲覧？ いくつか試して、どのワークフローがクリックするかを確認してください。

個人的には、プリントショップを運営して数百の注文をしていない限り、網点ツールに月$15を払うことはないでしょう。他のすべての人にとって、無料オプションで十分です。
