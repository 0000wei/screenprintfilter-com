# ScreenPrintFilter - Free Online Halftone Dot Filter

[![ScreenPrintFilter Screenshot](https://screenprintfilter.online/images/og-image.png)](https://screenprintfilter.online/)

**ScreenPrintFilter** is a free online tool that converts images into halftone dot patterns for screen printing and graphic design.

## ✨ Features

- **Halftone Conversion** — Transform any image into dot patterns
- **Adjustable Parameters** — Dot size, spacing, contrast, brightness
- **Dot Shapes** — Circle, square, diamond, line
- **Grid Rotation** — Rotate dot grid 0-360°
- **Original Colors** — Preserve or replace with custom colors
- **Multiple Formats** — Input JPG/PNG/WebP/GIF/BMP, output PNG

## 🔒 Privacy First

All processing happens locally in your browser. Your images never leave your device.
