Edit /home/wu/screenprintfilter-com/index.html to add an "Original Colors" checkbox in the toolbar, between the Color section and the Size section.

## What to change

### 1. Add a checkbox in toolbar HTML
Between the Foreground/Background color pickers and the Size group, add:

```
<label class="checkbox-label">
    <input type="checkbox" class="checkbox-sm" id="useOriginalColors" checked>
    Original Colors
</label>
```

### 2. Connect the checkbox
In the JS DOM Elements section, add:
```
const useOriginalColorsCheckbox = document.getElementById('useOriginalColors');
```

In setupEventListeners, add change listener:
```
useOriginalColorsCheckbox.addEventListener('change', handleControlChange);
```

In enableControls, add useOriginalColorsCheckbox to the controls array.

In resetParameters, add:
```
useOriginalColorsCheckbox.checked = true;
```

### 3. Modify the applyHalftone function
When `useOriginalColorsCheckbox.checked` is true:
- Skip the grayscale conversion step (the loop that converts RGB to gray)
- Instead, keep the original RGB values
- For each dot position, sample the ORIGINAL color (not grayscale) from the temp canvas
- Set `resultCtx.fillStyle` to that specific color BEFORE drawing each dot

When the checkbox is NOT checked:
- Keep existing behavior (foreground/background colors)

### 4. Update drawShape function (or the call to it)
When using original colors, call drawShape with a color parameter:
```
drawShape(resultCtx, centerX, centerY, dotRadius, shape);
```
Needs to change to accept an optional color parameter. If provided, set `ctx.fillStyle = color` before drawing.

### Important
- Keep all existing code paths working
- Default state: Original Colors = ON (checked)
- The slider value for Foreground/Background should still work when Original Colors is OFF
- Preserve Google Analytics, SEO, AI agent files, gallery, FAQ, footer

Use the Edit tool to make specific targeted changes. Do NOT rewrite the entire file.
