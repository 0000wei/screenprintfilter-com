## Bug: Canvas placeholder "Drop image here" click does nothing
The canvas placeholder area shows "Drop image here or click Load Image" text, but clicking on it does NOT trigger the file picker. The placeholder is inside the canvas-wrapper div.

Fix: Add a click event listener to the canvas wrapper or placeholder element that triggers fileInput.click().

There's already a Load Image button in the toolbar that works. The issue is the placeholder area itself is not wired to respond to clicks.

Implementation:
```js
// In setupEventListeners(), add:
canvasPlaceholder.addEventListener('click', function() {
  fileInput.click();
});
```

Make sure canvasPlaceholder has cursor:pointer CSS.
