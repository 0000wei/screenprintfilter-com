# Bug: 非 English 版本 :root CSS 变量是暗色 + 暗色规则重复

## 问题分析

有两个问题：

### 问题 1：`:root` 变量是暗色值
非英文版本的 `:root` 里定义的 CSS 变量全是暗色值（`--bg-primary: #0a0a0a` 等），应该跟英文版一样是亮色值。`:root` 是默认值（亮色模式），暗色模式由 `html[data-theme="dark"]` 覆盖。

### 问题 2：暗色 CSS 规则重复了两遍
每个非英文文件有两个 `<style>` 块。第一个 style 块（在 `</style>` 结束于约 955 行附近）里有暗色规则，第二个 style 块（lang-switcher 的 style，约 985-1095 行）里也有同样的暗色规则。导致暗色规则出现两次。

## 修复方案

### 第一步：修复 `:root` 变量

将所有 7 个非英文版本中 `:root {` 里的变量替换为英文版的亮色变量。

英文版的 `:root` 变量（这是正确的）：
```css
        :root {
            /* Light mode (default) */
            --bg-primary: #ffffff;
            --bg-secondary: #f3f4f6;
            --bg-tertiary: #e5e7eb;
            --text-primary: #1f2937;
            --text-secondary: #6b7280;
            --text-disabled: #9ca3af;
            --accent: #FF4500;
            --accent-hover: #FF5722;
            --border: #e5e7eb;
            --border-hover: #d1d5db;
            --success: #4CAF50;
            --radius: 8px;
            --shadow: 0 4px 12px rgba(0, 0, 0, 0.1);
            --shadow-lg: 0 12px 40px rgba(0, 0, 0, 0.15);
            --transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1);
        }
```

### 第二步：删除第二个 style 块中的重复暗色规则

第二个 `<style>` 块（包含 lang-switcher 样式的那个，约 985 行开始）里有一段重复的暗色 CSS，从 `html[data-theme="dark"] {` 开始，到最后一个 `html[data-theme="dark"] .footer-links a:hover {` 规则结束（约 1013-1070 行）。这段需要删掉。

具体来说，在第二个 style 块中，删除从这一行：
```css
        html[data-theme="dark"] {
```
一直到这一行（含）之间的所有内容：
```css
        html[data-theme="dark"] .footer-links a:hover {
            color: var(--accent);
        }
```

保留其后面的 `/* Theme Toggle */` 部分（.theme-toggle, .sun-icon, .moon-icon 等）。

### 第三步：第一个 style 块中的暗色规则保留
第一个 `<style>` 块中约 873-932 行的暗色规则是正确的，保留不动。

## 需要修改的文件
- `zh/index.html`
- `ja/index.html`
- `de/index.html`
- `fr/index.html`
- `es/index.html`
- `pt/index.html`
- `ar/index.html`

## 不要修改
- 英文版 `index.html`（它已经是正确的）

## 验证
修改后确认：
1. 每个非英文文件的 `:root` 变量都是亮色值（`--bg-primary: #ffffff`）
2. 每个非英文文件的暗色 `html[data-theme="dark"]` 规则只出现一次（在第一个 style 块中）
3. 第二个 style 块中不再有暗色规则（只有 lang-switcher + theme-toggle 相关样式）
4. 英文版 index.html 无变化
